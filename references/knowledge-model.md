# 从幻灯片提纲到知识体系：提取和覆盖模型

## 基本区分

- `explicit`: 幻灯片显式出现的概念、定义、数字、公式、标题、模型。
- `inferred_cluster`: 根据相邻章节或跨页编号能够可靠识别的同一知识簇。例如某主题连续出现“第1步…第6步”。标记为“结构归纳”，**不是授课者未提供的口述原文**。
- `external_expansion`: 用户授权进行知识拓展后，由通行管理学框架或核实的外部来源补充的解释。不得隐蔽替换课堂模型。
- `unsupported`: 材料不支持、缺页或证据相互矛盾，不得编造。

## 主题类型与说明深度

| 类型 | 自动发现线索 | 必须解释 |
|---|---|---|
| concept | 是什么、定义、含义、术语 | 定义、机制、意义、边界、场景 |
| framework | 模型、矩阵、维度、理论 | 变量、变量关系、逻辑、适用范围、局限 |
| comparison | VS、A/B、多种战略 | 分别定义、比较维度、优劣、选择依据 |
| process | 步骤、阶段、生命周期、设计、实施 | 目标、输入、逐步操作、输出、衔接、风险 |
| calculation | 公式、率、权重、分值、NPV、ROI | 变量单位、公式、假设、例子、限制 |
| case | 案例、事件、实验、调查 | 事实、推理、结论、可推广边界 |
| composite | 多页步骤+分散工具构成一项管理活动 | 单独标题、完整可执行方法、各步骤衔接与指标 |

## 隐含综合方法的识别规则

1. 对所有页标题、页眉、编号、时间顺序建立倒排索引。
2. 聚类相近术语；同一个主题下的“第1步……第N步”归为一个 process，即使跨越多个文件或不连续页。
3. 为流程找到管理任务动词：“设计”“建设”“制定”“执行”“评估”“改进”“诊断”“选择”“实施”。
4. 将任务转为学生可检索的标题，例如“薪酬体系设计的完整方法”。
5. 每个 composite 条目必须列出 `steps`、源页证据、首尾产出、`min_chars`、风险与例子。
6. 如果无法可靠判断某页是否属于该流程，保留疑点；不要强行创造步骤或题目。

## 原型案例：薪酬体系设计的漏项

由六张不同页面分别讲解：

1. 岗位价值评价：确定岗位相对价值，提供内部公平基础。
2. 外部薪酬调查：获得相似岗位市场薪酬，提供外部竞争力基准。
3. 薪酬现状诊断：识别薪酬倒挂、成本、内部压缩、关键岗位不足等问题。
4. 确定薪酬战略：领先、跟随、滞后或按人群混合定位。
5. 薪酬结构设计：分职级、档位、区间幅宽、相邻等级重叠及晋级规则。
6. 薪酬构成设计：固定工资、绩效、提成、奖金、福利与长期激励比例。

仅逐项解释不达标。综合知识需说明：为什么要按此顺序，上一阶段输出如何成为下一阶段输入，怎样落地实施、如何评估与定期修订。课件未明示的“实施、沟通、复核”等环节可以作为**通用管理扩展**，不假装老师原文。

## 反向试运行举例

- 战略管理：SWOT、选择战略、组织执行与评价分散讲解时，应还原“战略制定—执行—控制”全过程。
- 市场营销：STP、4P、渠道、消费者洞察分散出现时，应还原“市场分析—细分定位—营销组合—效果评价”。
- 公司财务：现金流、折现、NPV、IRR、敏感性分析分散出现时，应还原“一项投资项目的完整评估与决策流程”。
- 运营管理：流程识别、瓶颈、产能、质量改进、PDCA分散出现时，应还原“流程诊断与优化方法”。

这些只是说明识别机制，不是预设这几道题一定会考。

## 默认核查问题

- 我是按页面复制了内容，还是还原了可操作的知识结构？
- 如果学生要利用这些概念**完成一个管理设计任务**，手册中有连续步骤吗？
- 每个步骤说明了做什么、为什么和如何操作吗？
- 定义与实现细节是否足够长，能够独立阅读，不依赖课堂口头补充？
- 是否区分源材料事实、推论和外部扩展？
- 例子与数字是否真实有据，是否把研究中的相关系数误当百分比？
