# A4 开卷打印与 Word 版式规范

目标是**相同纸张承载更多可读知识**，而不是把字号缩小到难以阅读。

## 推荐默认

- A4竖版，黑白打印友好，无彩色大色块。
- 页边距通常上/下 1.3–1.6cm、左右 1.5–1.8cm，依据学校打印机可打印区域调整。
- 正文中文宋体/等价易读字体约9.5–10.5pt，行距约1.10–1.20，段后间距2–4pt；标题略大且加粗。根据页数限制做小幅调整，不低于足够可读的正文标准。
- 标题采用层级标题（可供 Word 导航窗格和查找），正文连续分页，不要一个模块强制新开一页。一个标题最多两级或三级，避免频繁占行。
- 为开卷检索，可增加一行紧凑目录或页眉主题提示；正文关键词可适度加粗，不要用大块留白做视觉排版。
- 表格仅用于确有比较价值的信息。表格行不宜被拆开；超长表格需分拆或改文字段落。
- 默认单栏排版；要双栏必须确认长公式和长表格不会变得难读。

## 验证流程

1. 输出 .docx；确认 ZIP 容器可解压、XML 结构可读、文件能重新打开。
2. 若工具支持，渲染为PDF并检查**实际页数**，不可凭 Word 段落数推测页数。
3. 检查首页、中间页、末页；重点检查表格断裂、字重、页眉页脚、过多空白、正文过小及重叠。
4. 若出现一整页下方1/3无内容且下一页仍有内容，优先检查强制分页、标题段落 `keep_with_next`、表格行禁止跨页、过高行距和巨大段前间距。
5. 最后一页自然内容不足不视为同等严重的排版问题，但也应判断能否通过紧凑排版减少总页数。
6. 对页数硬上限，超页即未通过；不能悄悄增加页数。先删除重复、来源套话与非必需装饰；再压缩排版。如果知识确实装不下，需要在交付时说明取舍，而不是让关键设计流程消失。

## 自动检查与局限

`scripts/audit_guide.py` 可在有渲染 PDF 时检查页数并对疑似空白进行提示；**脚本不能代替人工查看PDF页面**，对大量图形或图像型内容可能误报。
